# Dated validation evidence

Use [the validation index](../VALIDATION.md) to choose a relevant fixture, and
[current status](../STATUS.md) to distinguish implementation from acceptance.
Subdirectory plans, results and READMEs describe their named build, configuration,
date and hardware. Their old defaults, execution approvals and pending-work
statements do not override current source, portable guides or session permission.

Do not read every report for a project question. Follow the relevant feature or
status link, and preserve original evidence rather than rewriting an old result
to imply a new run. Local `.artifacts/` references may not exist in another clone.
